#PROJETO EM EXECUÇÃO#
🚗 Gestão Lava Jato- Sistema de Gestão para Oficinas e Lava Jatos
📖 Sobre o Projeto

O MECAJATO é uma aplicação web desenvolvida com Python e Django, criada para auxiliar na gestão operacional de oficinas mecânicas e lava jatos.

A plataforma tem como objetivo centralizar informações importantes do negócio, permitindo o gerenciamento eficiente de clientes, veículos, serviços realizados e acompanhamento das operações diárias.

Este projeto foi desenvolvido com foco no aprimoramento de habilidades em desenvolvimento web, arquitetura MVC, manipulação de banco de dados e construção de aplicações utilizando o framework Django.

🎯 Problema Resolvido

Muitas oficinas e lava jatos realizam o controle de clientes e serviços de forma manual, utilizando anotações em papel ou planilhas dispersas, o que pode gerar retrabalho, perda de informações e dificuldade no acompanhamento dos atendimentos.

O MECAJATO busca solucionar esse problema através de uma plataforma centralizada que permite:

Cadastro organizado de clientes;
Gerenciamento de veículos;
Controle dos serviços executados;
Acompanhamento do histórico de atendimentos;
Melhor organização das informações do negócio.
🚀 Funcionalidades

🏗️ Arquitetura Utilizada

O projeto utiliza o padrão arquitetural MVT (Model-View-Template) do Django.

Models

Responsáveis pela estrutura dos dados da aplicação.

Views

Responsáveis pelo processamento da lógica de negócio.

Templates

Responsáveis pela renderização das páginas para o usuário.
